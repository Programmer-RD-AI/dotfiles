# Agents Configuration

with my increase usage of agentic coding tools, i have found a agents.md/claude.md configuration that works best for my use cases, and that is what is provided within this dir. this will be updated in the long run as i use more tools and find better points of improvements.

there are some specific niche use cases that i have, the main one is:
- the draft pr review process between the agent and user, currently for most scenarios, you would review the code locally, but there really is not a proper workflow that can be done where you can review it as if you would in something like github prs, the closest thing i found was codex desktop but for something like claude, there is not a proper workflow, so this is the solution to it, where in a scneario in which we put up a pr (the agent does, in draft status), the us the user will go and add comments as if we are reviewing it, and the agent and we go back and forth in that draft status, and afterwards we make the pr ready for review, then that's it.
