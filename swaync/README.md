# swaync

sway notification center configuration.

## setup

```bash
ln -sf ~/.dotfiles/swaync ~/.config/swaync
```

## files

- `config.json` → notification + control center behavior.
- `style.css` and `colors.css` → visual styling.
- `themes/` → split css for notifications/control center.
- `icons/`, `images/` → assets used by widgets and controls.
