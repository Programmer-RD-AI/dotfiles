# waybar

waybar configuration for the hyprland/omarchy setup.

## setup

```bash
ln -sf ~/.dotfiles/waybar ~/.config/waybar
```

## files

- `config.jsonc` → module layout, click actions, and custom indicators.
- `style.css` → waybar appearance and module styling.
