# lazygit

git ui with nvim integration.

## setup

```bash
ln -sf ~/.dotfiles/lazygit ~/.config/lazygit
```

## config

- **Editor**: nvim
- **Pager**: delta
- **Theme**: Green borders
- **Icons**: Nerd Fonts v3

## custom keys

- `C` (files view) → Commit with message prompt
