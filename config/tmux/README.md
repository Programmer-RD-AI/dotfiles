# Tmux

Prefix: `Ctrl+a`

## Key Bindings

**Panes**
- `Ctrl+a |` → Split vertical
- `Ctrl+a -` → Split horizontal
- `Alt+Arrow` → Navigate (no prefix)
- `Ctrl+a Arrow` → Resize

**Copy Mode**
- `Ctrl+a [` → Enter copy mode
- `v` → Begin selection
- `y` → Copy and exit

**Config**
- `Ctrl+a r` → Reload config

## Features

- Vi keys
- Mouse support
- 50k scrollback
- Windows start at 1
