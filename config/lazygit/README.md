# Lazygit

Git UI with nvim integration.

## Config

- **Editor**: nvim
- **Pager**: delta
- **Theme**: Green borders
- **Icons**: Nerd Fonts v3

## Custom Keys

- `C` (files view) → Commit with message prompt

## Default Keys

Lazygit uses standard keybindings. Some helpful ones:
- `<space>` → Stage/unstage files
- `a` → Stage all
- `c` → Commit
- `P` → Push
- `p` → Pull
- `enter` → View file/commit details
- `?` → Show all keybindings
