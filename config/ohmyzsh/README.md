# Zsh

Zsh with Oh My Zsh config.

## Features

**Shell Options**
- Vi mode
- Auto-cd
- Command correction
- Directory stack

**Environment**
- Editor: nvim
- Visual: code
- Terminal: wezterm
- Homebrew paths

**Prompt**
- Git info
- System info command

> Similar aliases to bash config. Check `bash/README.md` for common commands.
