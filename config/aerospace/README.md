# Aerospace

Window manager for macOS.

## Key Bindings

**Modifier**: `Alt`

**Windows**
- `Alt+Arrow` → Focus window
- `Alt+Shift+Arrow` → Move window
- `Alt+f` → Fullscreen
- `Alt+t` → Open terminal

**Layout**
- `Alt+/` → Toggle tiles layout
- `Alt+,` → Toggle accordion layout
- `Alt+Shift+=/−` → Resize

**Workspaces**
- `Alt+1-9` → Switch workspace
- `Alt+Shift+1-9` → Move window to workspace
- `Alt+Tab` → Last workspace

**Config**
- `Alt+Shift+c` → Reload config

## Features

- Borders on active window
- 10px gaps
- Auto layout normalization
- Starts at login
